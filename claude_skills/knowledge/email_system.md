# QuikrClone — Email System

> Complete email system specification. All emails are sent via Gmail SMTP with branded HTML templates.

---

## SMTP Configuration

| Setting | Value |
|---------|-------|
| Protocol | SMTP with STARTTLS |
| Host | `smtp.gmail.com` |
| Port | `587` |
| Auth | Gmail App Password (NOT regular password) |
| From Header | `QuikrClone <your-email@gmail.com>` |

---

## Email Architecture

### Core Functions (in `app/utils/email.py`)

| Function | Trigger | Description |
|----------|---------|-------------|
| `send_welcome_email(to, name)` | After signup | Welcome message with CTA to explore |
| `send_verification_email(to, token, name)` | After signup + manual from Profile | Verify link (24hr expiry) |
| `send_forgot_password_email(to, token, name)` | /forgot-password submission | Reset link (1hr expiry) |
| `send_password_changed_email(to, name)` | After reset or change password | Confirmation with timestamp |
| `send_delete_account_email(to, name, code)` | Account deletion request | 6-digit confirmation code |

### Internal Architecture

```
_send_html_email(to, subject, html)     ← Core sender (SMTP connection)
    ↑
_email_wrapper(content)                 ← Branded HTML template wrapper
    ↑
send_verification_email(...)            ← Public function (generates content)
send_welcome_email(...)
send_forgot_password_email(...)
send_password_changed_email(...)
send_delete_account_email(...)
```

## Email Types Detail

### 1. Welcome Email
- **Subject:** "Welcome to QuikrClone! 🎉"
- **Content:** Greeting, feature list (Post ads, Browse, Chat, Favorites), "Start Exploring" CTA
- **Trigger:** Automatic on signup

### 2. Verification Email
- **Subject:** "Verify Your QuikrClone Account ✅"
- **Content:** "Verify My Email" button with token link, raw link fallback, 24hr expiry notice
- **Link:** `{FRONTEND_URL}/verify?token={token}`
- **Trigger:** Auto on signup + manual from Profile "Verify Account" button

### 3. Forgot Password Email
- **Subject:** "Reset Your QuikrClone Password 🔐"
- **Content:** "Reset Password" button (red), raw link fallback, 1hr expiry warning
- **Link:** `{FRONTEND_URL}/reset-password?token={token}`
- **Security:** Always returns success (prevents email enumeration)

### 4. Password Changed Confirmation
- **Subject:** "Your Password Has Been Changed 🔒"
- **Content:** Success notice with timestamp, security warning if not initiated by user
- **Trigger:** After password reset OR password change from Profile

### 5. Account Deletion Code
- **Subject:** "QuikrClone: Account Deletion Code ⚠️"
- **Content:** Warning message, large formatted code display, safety notice
- **Code:** Static 6-digit code displayed in a dashed-border box

## Fallback Behavior

If SMTP is not configured (no `SMTP_HOST`, `SMTP_USER`, or `SMTP_PASSWORD`):
- Logs email content to console
- Returns `True` (flow continues without blocking)
- Development-friendly: no SMTP needed to test the flow

## Token System

| Token Type | Expiry | Generated By | Validated By | Single-Use? |
|-----------|--------|--------------|-------------|-------------|
| Verification | 24 hours | JWT with `sub=user_id` | `/verify?token=xxx` | Yes (checks `is_verified`) |
| Password Reset | 1 hour | JWT with `sub=user_id, token_version=N` | `/reset-password` | Yes (increments `token_version`) |
| Access Token | 30 minutes | Login endpoint | Every authenticated request | No (until password change) |
| Refresh Token | 7 days | Login endpoint | `/refresh-token/` | Rolling (new pair on refresh) |
